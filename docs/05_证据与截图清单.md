# 最小证据闭环：每次运行需要交什么

| 步骤 | 截图（只作为索引） | 不可缺少的机器原件 | 验收 |
|---|---|---|---|
| 环境 | `python --version`、GitHub run主页 | commit SHA、runner OS、Python/Docker/gh版本 | 可复现 |
| B0 N01 | Actions绿灯、Dev QA Staging状态 | workflow YAML、真实健康检查JSONL、Docker logs | 全PASS |
| B0 B01 | Actions红灯、QA 503 | 原始exit code、QA HTTP日志、失败run artifact | 预期失败且保留 |
| B1 N01 | Attestation及CLI PASS | 签发workflow、bundle/校验JSON、构件SHA | 真实证明存在 |
| B1 tamper | 校验失败页/终端 | 修改前后文件SHA、verify stderr和非零退出码 | 篡改被拒 |
| B2 A101 | 关闭判定输出 | 独立raw inventory、derived disposition修改副本、case JSON、prototype输出 | OPEN（仅教学） |
| B2 A201 | 后继关联缺失 | Finding时间、缺关系record、审计输出、旧快照hash | NFI（仅教学） |
| 正式 E2 | 三组run对照 | Oracle冻结标签、场景矩阵、相同commit和基线策略、逐次CSV | 可复算 |
| E3 | 运行计时显示 | 每次wall-clock/CPU/RSS原始记录、git diff、工时记录 | 实测不推测 |

**命名规范**：`<run_id>__<stage>__<scenario>__<what>.png`。同名`.json` sidecar写UTC时间、对应日志、截图出处、脱敏处理。所有失败/重试也需保留。截图不能代替机器原件。

**严禁**：在教程脚手架中输入真实项目个人信息/密钥；将本地演示冒充GitHub已运行；将模拟B2称论文Algorithm 1；将B1工具不支持记为Missed；将人工补写的ZHX关系伪装成Recorded。
